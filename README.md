# reseau-hors-ligne-Kinshasa-

Menu réseau hors ligne en HTML, CSS et JavaScript.

## Aperçu

Cette application est un tableau de bord simple pour simuler le suivi d’un réseau local hors ligne. Elle affiche :

- l’état général du réseau ;
- les indicateurs Wi‑Fi, LAN, DNS et serveurs ;
- des actions rapides pour manipuler le réseau ;
- un journal système local.

## Démarrage rapide

1. Ouvrez le fichier `index.html` dans un navigateur moderne.
2. Utilisez le bouton “Lancer le diagnostic” pour simuler une vérification.
3. Cliquez sur les actions rapides pour modifier l’état du réseau.

## Fichiers

- `index.html` : structure de l’interface
- `style.css` : thème visuel et mise en page
- `script.js` : logique de simulation du réseau

## Objectif

Le projet sert de base légère pour un menu ou centre de surveillance réseau, sans dépendance externe.
